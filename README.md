# Qorgan

Open-source AI-инженер по безопасности для ваших GitHub-репозиториев. Qorgan запускает
проверенные сканеры, а агент разбирает их вывод: читает код вокруг каждой находки, отсеивает
ложные срабатывания, открывает PR с исправлениями и ревьюит PR команды.

Разворачивается у вас: код репозиториев не уходит никуда, кроме LLM-провайдера, которого вы
сами указали своим ключом.

## Быстрый старт

Нужен только Docker.

```bash
git clone https://github.com/qorganapp/qorgan.git
cd qorgan
make up            # создаст .env со случайными секретами, соберёт и поднимет всё
```

Без `make`:

```bash
cp .env.example .env     # замените JWT_ACCESS_SECRET и JWT_REFRESH_SECRET на случайные строки
docker compose up --build
```

Откройте <http://localhost:8080>. Первая сборка занимает несколько минут: образ воркера
включает все сканеры.

**Посмотреть без настройки:** <http://localhost:8080/?mock=1> — демо-режим на реальном выводе
сканеров по тестовому уязвимому репозиторию, с вердиктами агента и чатом.

**Для реальных сканов** заполните в `.env`:

- `GITHUB_*` — свой GitHub App (права и события перечислены в `.env.example`). Вебхукам GitHub
  нужен публичный адрес API, локально подойдёт любой туннель.
- `ANTHROPIC_API_KEY` — ключ для агента. `LLM_PROVIDER=none` выключает агента, сканеры
  продолжают работать.

## Что внутри

| Модуль | Что ищет | Инструменты |
|---|---|---|
| **Supply Chain** | Уязвимые и вредоносные пакеты, тайпсквоттинг | osv-scanner, trivy, typosquat |
| **Code Audit** | Инъекции, SSRF, небезопасная десериализация | semgrep |
| **Secret Sweep** | Ключи и токены в коде и истории git | gitleaks |
| **Infra Guard** | Terraform, Kubernetes, Docker | checkov, trivy config |

Агент поверх сканеров:

- **Триаж** — вердикт по каждой находке: реальная или ложная, достижима ли, насколько критична
  именно в этом репозитории.
- **Фиксы через PR** — минимальное исправление, повторный запуск сканера, и только потом PR из
  ветки `qorgan/fix-*`.
- **Ревью PR** — сканирует только изменения и оставляет inline-комментарии.
- **Чат** — вопросы о безопасности репозитория.

## Границы агента

- В default-ветку не пишет и ничего не мержит: все изменения идут только через PR.
- Approve на PR не ставит.
- CI-конфигурацию менять не может.
- Код репозитория считает недоверенными данными; найденные секреты маскируются до отправки в
  модель.
- Каждый шаг сохраняется в журнал и виден в разделе **Agent**.

## Структура

```
apps/
  web/    Angular — дэшборд                       (README внутри)
  api/    NestJS — API и воркер со сканерами и агентом   (README внутри)
docker-compose.yml       весь стек: postgres, redis, api, worker, web
docker-compose.dev.yml   порты базы и Redis для локальной разработки
Makefile                 короткие команды (make help)
```

```
браузер ─► web (Caddy :8080) ─ /api ─► api ─► Postgres
                                        │ BullMQ
                                        ▼
                                      Redis ─► worker: clone → сканеры → триаж → агент
```

## Разработка

Нужны Node 24 и pnpm 11 (`corepack enable`).

```bash
pnpm install
make dev-deps                              # Postgres и Redis в Docker
cp apps/api/.env.example apps/api/.env     # заполнить JWT_*
pnpm dev:api                               # API на :3000
pnpm dev:web                               # фронтенд на :4200, /api проксируется на :3000
```

Воркеру нужны сканеры в PATH, поэтому его проще запускать в Docker:
`docker compose up --build worker`.

```bash
pnpm test     # тесты API и фронтенда
pnpm lint     # линтер API
pnpm build    # сборка обоих приложений
```
